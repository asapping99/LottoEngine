# LottoEngine

이 프로젝트는 간단한 로또 엔진 예시 코드입니다. `config` 폴더의 XML 파일을 읽어
데이터베이스 연결 정보를 파싱하고, 이를 이용해 애플리케이션을 실행할 수 있도록
기본 구조를 제공합니다.

## 디렉터리 구조

- `src/main/` - 애플리케이션의 진입점인 `main_lotto.py`가 위치합니다.
- `src/util/` - XML 파싱과 데이터베이스 연결 등 공통 유틸리티 모듈이 있습니다.
- `config/` - XML 형식의 설정 파일을 저장하는 곳입니다.

## 실행 방법

```
python src/main/main_lotto.py
```

실행 시 `config` 폴더의 XML 파일을 읽어 `XMLParse` 클래스를 통해 파싱한 결과를
`xml_parse_map` 딕셔너리로 보관합니다. 현재 데이터베이스 연결 부분은
샘플 코드로, 실제 연결 로직은 구현되어 있지 않습니다.

## 요구 사항

- Python 3.8 이상

## 라이선스

이 저장소는 특별한 라이선스 없이 예시 용도로 제공됩니다.
